Ask your Odoo data in plain words

From ChatGPT, Claude or the Speak To Your Database app.

Real numbers from live Odoo data — sales, invoices, stock, CRM, projects.

Works in the AI app you already use

  • ChatGPT: install the Speak To Your Database plugin.
  • Claude: add the connector from Claude's directory.
  • Also VS Code (GitHub Copilot), Le Chat, any app that supports remote MCP servers, or the Speak To Your Database web app.

Example questions:

  • “How much revenue did we make last month, compared with the month before?”
  • “Which customer invoices are overdue, and how much does each customer owe?”
  • “Show all sales orders grouped by customer and status, with the number of orders and the total amount.”
  • “Top 10 products by sales this year.”

Answers state the period and the definition they used (for example, revenue = posted customer invoices, excluding tax).

Two ways to connect

  1. Odoo API key — fastest, no module to install. Works on Odoo Online (Custom plan), Odoo.sh and on-premise. Everyone in your Speak To Your Database workspace sees what that one Odoo user can see.
  2. This module (the Bridge) — for teams who want each person linked to their own Odoo user and a narrower data surface: only allow-listed models and fields, scoped to the company, through a token you can rotate. No Odoo password or API key is stored. Odoo.sh and on-premise only.

Both are read-only.

What this module does

  • Read-only by design: it uses the Odoo ORM, sends no SQL, and has no write path.
  • Only allow-listed models and filtered fields are readable.
  • Scoped to the companies of the configured connector owner.
  • Each Speak To Your Database user is linked to an Odoo user.
  • Access through a token you generate, rotate or revoke on the Connection Setup page; the token is stored hashed.

Set up in 3 steps

  1. Install the module.
  2. In Odoo, open Connection Setup and generate a token.
  3. In Speak To Your Database, add an Odoo connection and paste the token.

Answers you can check

Each answer shows how it was found: which records were read, the filters, and the period. Long lists are capped, and secrets are always hidden.

Supported business areas

Customers and contacts Sales orders and quotations
Products and variants Inventory and stock levels
Purchase orders Customer invoices and vendor bills
CRM leads and opportunities Projects and tasks
Company information User directory and access metadata

Supported areas depend on the Odoo apps installed on your database.

What is not supported

  • Odoo Online (odoo.com) cannot install this module. On the Custom plan, connect with an Odoo API key instead — no module needed.
  • Creating, changing or deleting anything in Odoo.
  • Raw SQL.
  • Exact per-user record-rule parity: answers are scoped to the linked user and company, but not every custom record rule is reproduced.
